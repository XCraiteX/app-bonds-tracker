# Bonds Tracked | Client App

Приложение помогает следить за своими инвестициями и контролировать выплаты по ним в понятном календаре. Очень помогает инвесторам, которые пользуются не сильно продвинутыми терминалами для инвестирования.

> Внимание! ~20% Frontend части было написано ИИ, т.к. я не смог понять как сделать грамотно календарь. Основной проект фронта был написан очень давно и вообще на Python FastAPI. Я решил переписать проект на GO, т.к. хотел сделать полноценное приложение, а так-же перейти на golang.

#### Стек:

- Golang + Whails
- NEXTjs & React, TypeScript, react-icons
